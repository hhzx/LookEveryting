## v0.1–v0.4 — 已完成

- [x] 深色极简设计系统、中英切换、文件关联
- [x] 图片：预览优先、原图按需、缩放/平移、棋盘格、filmstrip 滚轮
- [x] 视频：MF 内嵌、进度条 seek、逐帧、全局解码线程

- [x] 全屏 F11、状态栏、加载动画、CJK 字体打包
