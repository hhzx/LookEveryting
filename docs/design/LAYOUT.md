# LookEveryting 布局与响应式规范

> 配套 [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md) · 定义断点、布局模式与 DPI 适配

---

## 1. 断点系统

| 模式 | 窗口宽度 | 代号 | 典型场景 |
|------|----------|------|----------|
| Compact | < 720px | `compact` | 小窗、分屏 |
| Comfortable | 720–1279px | `comfortable` | 笔记本默认 |
| Spacious | ≥ 1280px | `spacious` | 台式机、超宽屏 |

检测逻辑（每帧或 resize 时）：

```rust
fn layout_mode(width: f32) -> LayoutMode {
    if width < 720.0 { LayoutMode::Compact }
    else if width < 1280.0 { LayoutMode::Comfortable }
    else { LayoutMode::Spacious }
}
```

## 2. 三种布局模式

### 2.1 Spacious（宽屏 · 默认开发目标）

```
┌────────────────────────────────────────────────────────────────┐
│ TitleBar  40px                                                 │
├──────────┬─────────────────────────────────────┬─────────────────┤
│ SideRail │                                     │ InfoDrawer      │
│ 240px    │         MediaViewport               │ 280px           │
│          │         (flex: 1)                   │ (collapsible)   │
│          │                                     │                 │
├──────────┴─────────────────────────────────────┴─────────────────┤
│ FloatingToolbar  44px + 12px margin                            │
└────────────────────────────────────────────────────────────────┘
```

| 区域 | 行为 |
|------|------|
| SideRail | 默认展开，可折叠为 48px 图标模式 |
| InfoDrawer | 默认收起，按 `I` 展开 |
| Toolbar | 底部居中浮层 |

### 2.2 Comfortable（中等窗口）

```
┌────────────────────────────────────────────────────────────────┐
│ TitleBar                                                       │
├────┬───────────────────────────────────────────────────────────┤
│48px│              MediaViewport                                │
│icon│                                                           │
├────┴───────────────────────────────────────────────────────────┤
│ FloatingToolbar                                                │
└────────────────────────────────────────────────────────────────┘

InfoDrawer → 右侧覆盖式抽屉 (320px)，带 scrim 遮罩
SideRail   → 仅图标模式 (48px)，悬停显示 tooltip
```

### 2.3 Compact（窄窗口）

```
┌──────────────────────────────────────┐
│ TitleBar (文件名缩短)                 │
├──────────────────────────────────────┤
│                                      │
│         MediaViewport (100%)         │
│                                      │
├──────────────────────────────────────┤
│ FloatingToolbar (精简按钮)            │
└──────────────────────────────────────┘

SideRail   → 隐藏，通过 [☰] 全屏抽屉唤出
InfoDrawer → 全屏抽屉 (100%)
工具栏      → 仅保留核心：◀ ▶ Fit − + ℹ
```

## 3. 查看模式布局（内容优先）

打开文件后，默认进入 **Viewer Mode**，侧栏自动收起。

### 3.1 沉浸模式状态机

```
                    ┌─────────────┐
         打开文件 →  │   VIEWER    │ ← 默认：仅画布 + 底部工具栏
                    └──────┬──────┘
                           │ 3s 无操作
                    ┌──────▼──────┐
                    │  IMMERSIVE  │ ← 工具栏隐藏，纯画布
                    └──────┬──────┘
                           │ 鼠标移入底部 / 任意键
                    ┌──────▼──────┐
                    │   VIEWER    │
                    └─────────────┘
                           │ 按 I
                    ┌──────▼──────┐
                    │ VIEWER+INFO │ ← 工具栏 + 信息抽屉
                    └─────────────┘
                           │ 按 B
                    ┌──────▼──────┐
                    │   BROWSE    │ ← 浏览模式，显示侧栏+网格
                    └─────────────┘
```

### 3.2 全屏 (F)

- 隐藏 TitleBar
- 画布 100%
- 工具栏同沉浸规则
- `Esc` 退出全屏

## 5. DPI 与缩放

### 5.1 缩放策略

```
ui_scale = clamp(system_dpi_scale × user_density, 0.85, 1.5)
```

| 用户设置 | density 乘数 |
|----------|-------------|
| 紧凑 | 0.9 |
| 标准 | 1.0 |
| 大号（无障碍） | 1.15 |
| 跟随系统 | 1.0 × system |

### 5.2 实现（eframe）

```rust
// 启动时
let scale = settings.ui_density * ctx.native_pixels_per_point();
ctx.set_pixels_per_point(scale.clamp(0.85, 1.5));
```

### 5.3 画布 vs UI 缩放

| 层 | 是否随 UI 缩放 | 说明 |
|----|---------------|------|
| 图片/视频/3D 画布 | 否 | 始终像素级渲染，占满可用区域 |
| 工具栏/面板/文字 | 是 | 跟随 ui_scale |
| 缩略图网格 | 部分 | 列数自适应，缩略图尺寸 × ui_scale |

### 5.4 高分屏测试矩阵

| 分辨率 | DPI | 预期 |
|--------|-----|------|
| 1920×1080 | 100% | 标准布局 |
| 2560×1440 | 125% | UI 略大，画布清晰 |
| 3840×2160 | 150% | UI 上限 1.5x，不过大 |
| 1366×768 | 100% | Compact 断点测试 |

## 6. 最小窗口与溢出

| 约束 | 值 |
|------|-----|
| min-width | 480px |
| min-height | 360px |
| 文件名最大宽 | 工具栏剩余空间 - 120px |
| 长路径 | 中间省略 `...` |
| 面板最小宽 | Compact 下 InfoDrawer 100% |

低于最小尺寸：禁止继续缩小（winit `set_min_inner_size`）。

## 7. 内容类型布局差异

### 图片

- 画布：纯黑 `#000000`
- 图片居中，保持宽高比
- Fit 模式：完整显示，留黑边
- 100% 模式：原始像素，可平移

### 视频

- 画布：纯黑
- 视频居中，letterbox
- PlaybackBar 替代 FloatingToolbar
- 控制条始终贴底（可沉浸隐藏）

### 3D

- 画布：纯黑或极深灰 `#0A0A0B`
- ModelToolbar 顶部居中浮层
- 右下角：操作提示 `左键旋转 · 滚轮缩放`（caption, 5s 后淡出）

## 9. 窗口状态持久化

保存到 `~/.config/LookEveryting/settings.toml`：

```toml
[window]
width = 1440
height = 900
x = 100
y = 100
maximized = false

[ui]
layout_mode_preference = "auto"  # auto | always-compact
sidebar_collapsed = false
info_panel_open = false
last_browse_path = "C:/Users/..."
```
