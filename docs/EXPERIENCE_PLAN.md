# LookEveryting — 极致体验专项计划（Experience Extreme）

> 功能计划见 `LEARNING_PLAN.md`。  
> **本文只谈体验**：速度感、沉浸感、手感、信息克制、失败友好、一致性。  
> 口号：**内容永远是主角；界面只在需要时出现；每一次操作都有即时反馈。**

---

## 0. 什么叫「体验极致」

不是功能最多，而是用户感觉：

1. **瞬开** — 双击文件，画面几乎立刻出现  
2. **零犹豫** — 不用找按钮，键盘/手势自然就对  
3. **不抢戏** — 看图时几乎只有图；控件来去安静  
4. **连得顺** — 翻文件夹像翻相册，没有白屏、闪烁、跳动  
5. **错得好** — 打不开时告诉你原因和下一步，不冷冰冰报错  
6. **一种语言** — 图 / 视频 / 模型，缩放、导航、全屏逻辑统一  

**对标体感（不是功能对标）：**
- 翻图速度 → **qView**
- 沉浸与精致 → **ImageGlass**
- 播放手感 → **mpv + Celluloid OSC**
- 模型「打开就好看」→ **F3D**

## 1. 体验北极星指标（必须能量化）

| 指标 | 目标 | 测量方式 |
|------|------|----------|
| 冷启动到可交互 | ≤ **400ms** | 启动到空状态可点「打开」 |
| 关联打开首帧（缓存冷） | ≤ **150ms** 出预览；≤ **400ms** 出清晰图 | 日志时间戳 |
| 关联打开首帧（缓存热） | ≤ **50ms** | 切回已看文件 |
| 文件夹相邻切换 | ≤ **80ms** 感知（预览或缓存） | 连按 ←→ 不白屏 |
| 输入到画面反馈 | ≤ **1 帧**（~16ms） | 缩放/平移/旋转无“粘滞” |
| 工具栏显隐动画 | **120–200ms**，ease-out | 不闪烁、不挡内容中心 |
| 全屏进出 | ≤ **200ms**，无布局跳动 | 缩略图/侧栏淡出而非硬切 |
| 错误可理解率 | 用户能说清「下一步」≥ 90% | 文案走查 |

未达标的功能，**默认不算完成**，即使代码已合并。

## 2. 体验宪法（10 条硬规则）

### C1. 内容优先
第一屏只允许：媒体内容 + 最多一条轻提示。  
禁止：卡片墙、统计条、促销式徽章、堆叠浮动标签。

### C2. 铬合金（Chrome）可消失
标题栏 / 工具栏 / 缩略图条 / 侧栏：  
- 沉浸/全屏时自动隐藏  
- 鼠标移到边缘再唤出  
- 唤出带淡入，不要突然蹦出  

### C3. 永远有「当前帧」
切换文件时：**旧画面保留到新预览到达**（crossfade 或 hold），禁止黑屏/“正在加载”独占全屏超过 200ms。

### C4. 指针为中心
滚轮缩放永远绕指针；双击适应；中键/拖拽平移。三种媒体交互语义对齐。

### C5. 键盘是一等公民
所有高频操作必须有快捷键；`?` 可呼出速查。  
快捷键冲突表必须单一真相源（文档 + 代码常量）。

### C6. 反馈即时且克制
点击 → 100ms 内视觉态变化；  
Toast ≤ 2 行；成功操作用微反馈，不弹窗。

### C7. 信息分层
- L0 状态栏：序号、分辨率、缩放%、时长（一行）  
- L1 悬停/快捷键：临时提示  
- L2 信息面板：EXIF / 模型统计（主动打开）  
默认只显示 L0。

### C8. 失败可行动
每个错误必须包含：**原因 + 建议动作**（重试 / 用系统打开 / 安装编解码器说明）。

### C9. 动画服务于空间感
只用：淡入淡出、位移跟随、进度补间。  
禁止：弹跳、过度发光、无意义循环动效。

### C10. 密度可适应
窗口变窄时：侧栏收起 → 缩略图保留 → 工具栏图标化。  
断点行为可预期，不突然换一套 UI。

## 3. 体验地图（按场景拆解）

### 3.1 打开瞬间（First Impression）

| 步骤 | 极致做法 | 现状差距 |
|------|----------|----------|
| 双击关联启动 | 启动画面极简或直接进内容；字体已就绪无豆腐 | 有字体打包；启动仍可再压 |
| 首包字节 | 先 512px 预览上屏，再升清晰 | 已有 staged decode |
| 无文件启动 | 大面积拖放热区 + 一句文案 + 一个主按钮 | 空状态偏朴素 |
| 拖入文件 | 拖入时窗口高亮边框；松手立即打开 | 仅打开，缺拖入高亮 |

**专项任务 E-OPEN**
1. Hold-previous-frame 切换（无黑场）  
2. 拖放悬停高亮  
3. 空状态视觉升档（仍保持克制）  
4. 启动路径：跳过不必要同步 IO  

### 3.2 浏览文件夹（Album Flow）

对标 qView「连按方向键如流水」。

| 能力 | 极致标准 |
|------|----------|
| ←→ / 滚轮（可配置） | 切换无闪烁；预取 ±2 |
| 底栏 filmstrip | 滚轮横向、拖拽、点击；当前项始终可见 |
| 侧栏列表 | 虚拟列表（千级文件不卡）；选中同步 |
| 切到视频/模型 | 控件形态平滑切换，不整页刷新感 |

**专项任务 E-BROWSE**
1. 切换 crossfade（80–120ms）  
2. filmstrip 惯性滚动（可选）  
3. 键盘按住连发有加速曲线（前 3 次慢，之后快）  
4. 当前缩略图选中态更清晰（不止描边）  

### 3.3 看图手感（Image Feel）

对标 ImageGlass / qView。

| 交互 | 极致标准 |
|------|----------|
| 缩放 | 指针中心；步进细腻；有最小/最大阻尼 |
| 100% | 像素锐利（Nearest）；大图按需解码有角标「加载原图…」但不挡图 |
| 适应 | 双击 / `F` / `0`；动画补间到 fit（可选） |
| 平移 | 放大后左键拖；未放大时左键可定义为切换（可设置） |
| 透明图 | 棋盘格不闪、不抢色 |

**专项任务 E-IMAGE**
1. 缩放阻尼与平滑插值（已有基础，调参到「润」）  
2. Fit ↔ 100% 短补间（120ms）  
3. 像素模式自动切换插值  
4. 多显示器 DPI 正确（每屏独立）  

### 3.4 看视频手感（Video OSC）

对标 mpv OSC + Celluloid。

| 交互 | 极致标准 |
|------|----------|
| 控件 | 仅底部一条；自动隐藏；鼠标移动唤出 |
| 进度条 | 可拖；悬停显示时间；拖动不卡顿 |
| 空格 | 播放/暂停；画面中央短促图标反馈（淡出） |
| 双击 | 全屏（可关） |
| 音量 | 滚轮（需修饰键或仅在控件区）避免与切图冲突 |

**专项任务 E-VIDEO**
1. OSC 自动显隐（与工具栏同一套 reveal 逻辑）  
2. 中央 Play/Pause 幽灵图标（400ms 淡出）  
3. Seek 预览时间气泡  
4. 缓冲/解码中：角落细进度，不盖住画面  

### 3.5 看模型手感（3D Presence）

对标 F3D「打开就位」。

| 交互 | 极致标准 |
|------|----------|
| 打开 | 相机自动框住模型；灯光默认好看 |
| 拖拽 | 轨道旋转跟手；惯性可选 |
| 滚轮 | 平滑缩放；近裁远裁不「穿帮」 |
| 提示 | 首次 5s 后淡出操作提示 |
| 线框/实体 | 切换无重建卡顿 |

**专项任务 E-MODEL**
1. 打开动画：distance 从 1.2× 收到 fit（200ms）  
2. 旋转阻尼  
3. HUD 淡入（不常驻刺眼）  
4. 加载中显示包围盒线框占位  

### 3.6 沉浸与全屏（Immersion）

| 模式 | 行为 |
|------|------|
| 普通 | 标题栏 + 可选侧栏 + 缩略图 |
| 沉浸 | 工具栏自动隐藏；移底唤出 |
| 全屏 F11 | 无边框；缩略图默认隐藏；Esc 退出 |
| 幻灯片 | 全屏 + 自动下一张；鼠标唤醒控件 |

**专项任务 E-IMMERSIVE**
1. 模式切换动画统一  
2. 底边 / 顶边唤出热区（已有 token，需真正接线）  
3. 多显示器全屏到「当前指针所在屏」  

### 3.7 错误与空态（Trust）

| 场景 | 极致文案结构 |
|------|----------------|
| 不支持格式 | 「无法预览 .xyz」+「可尝试用系统应用打开」按钮 |
| 视频解码失败 | 「缺少编解码器或文件损坏」+「系统播放器」+「重试」 |
| 模型无网格 | 「已读取文件，但没有可显示的几何体」 |
| 权限 | 「没有权限读取该文件」 |

**专项任务 E-TRUST**
1. 统一 ErrorAction 结构（message + actions[]）  
2. Toast / 模态分级（轻错 Toast，重错居中卡片）

## 4. 动效与手感规范

沿用 `cap-ui/motion.rs`，并强制执行：

| Token | 值 | 用途 |
|-------|-----|------|
| FAST | 120ms | 按钮态、图标反馈 |
| NORMAL | 200ms | 面板显隐、模式切换 |
| SLOW | 300ms | 幻灯片淡变（可选） |

**缓动：** 默认 ease-out；禁止 bounce。  
**工具栏：** 无操作 `3000ms` 隐藏；底边 `80px` 热区唤出（token 已有，**必须接到 UI**）。  
**切图：** 推荐 80–120ms 透明度交叉；若性能不够则 hold-frame（零动画但无黑场）。

## 5. 输入与快捷键体验包

### 5.1 统一快捷键（体验层）

| 键 | 图 | 视频 | 模型 |
|----|----|------|------|
| ←→ / ↑↓ | 上一张/下一张 | 同左（Shift+←→ 逐帧） | 同左 |
| 空格 | 幻灯片暂停/继续 | 播放/暂停 | — |
| F / 0 | 适应 | 适应画面 | 重置相机 |
| 1 | 100% | — | — |
| F11 | 全屏 | 全屏 | 全屏 |
| Esc | 退出层叠 UI / 全屏 | 同左 | 同左 |
| I | 信息 | 信息 | 信息 |
| ? | 快捷键帮助 | 同左 | 同左 |
| M | — | 静音 | — |

### 5.2 手势（Windows）
- 双指捏合缩放（触控屏）  
- 双指拖拽平移  
- 触控板双指滚动：图=缩放或平移（设置项）；缩略图条=横向  

### 5.3 发现性
- 首次启动 1 次「轻引导」：3 条气泡（打开、方向键、F11），可跳过且不再烦  
- `?` 面板：分组、可搜索、显示当前模式可用键

## 6. 视觉体验（不是换皮，是克制的精致）

1. **对比度**：正文 ≥ WCAG AA；弱提示用 muted，不靠过小字号  
2. **焦点环**：键盘导航时可见 focus，不依赖鼠标悬停才能用  
3. **选中态**：缩略图选中 = 边框 + 微提亮，勿用刺眼霓虹  
4. **加载**：角标/细环，禁止大块模态转圈盖住已有预览  
5. **中文排版**：字号阶梯固定（已有 typography）；避免一行里中英大小失衡  
6. **棋盘格**：低对比，不抢走透明图主体

## 7. 体验专项里程碑（与功能版解耦）

### EX-1「无黑场浏览」（1 周）— 最高优先级
- [ ] 切文件 hold-previous-frame  
- [ ] 预览到达 crossfade 或瞬间替换但不闪黑  
- [ ] 加载指示改为角标  
- [ ] 缩略图选中/滚动手感再打磨  

**验收：** 盲测 20 人，≥15 人认为翻图「比系统照片更跟手」。

### EX-2「沉浸闭环」（1 周）
- [ ] 工具栏真正 auto-hide + 热区唤出  
- [ ] 全屏进出无跳动  
- [ ] 视频 OSC 与工具栏显隐逻辑合并  
- [ ] 中央播放反馈图标  

**验收：** 全屏看视频 3 分钟，控件不常驻挡字幕区（底部安全区）。

### EX-3「手感抛光」（1–2 周）
- [ ] 缩放/旋转阻尼参数表（可调，有默认甜区）  
- [ ] Fit/100% 短补间  
- [ ] 快捷键帮助 `?`  
- [ ] 错误可行动  
- [ ] 拖放高亮  

**验收：** 对照 qView/ImageGlass/F3D 体验清单勾选 ≥ 80%。

### EX-4「精致默认」（与 v0.6 画质并行）
- [ ] 模型打开即位 + 短入场  
- [ ] 像素图 Nearest  
- [ ] 多 DPI / 多屏全屏正确  
- [ ] 幻灯片淡变

## 8. 体验评审机制（保证「极致」可执行）

### 8.1 每周体验走查（30 分钟）
固定脚本：
1. 关联打开大 JPG  
2. 连按 ←→ 30 次  
3. 滚轮缩放 + 拖拽  
4. 打开 MP4，空格，拖进度条，F11  
5. 打开 STL/GLTF，旋转缩放  
6. 打开损坏文件  

记录：卡顿、闪烁、挡内容、文案困惑。**每条必进 Issue，标 `experience`。**

### 8.2 合并门禁
带 `experience` 标签的 PR，需回答：
- 是否引入黑场/闪烁？  
- 是否增加常驻挡内容的 UI？  
- 键盘能否完成？  
- 失败是否可行动？  

### 8.3 竞品体感对照表（活文档）
每季度用同一文件夹打分 1–5：启动、翻页、缩放、沉浸、错误。目标：**总分不低于 qView+ImageGlass 均值**。

## 11. 成功定义（一句话）

> 用户关掉 LookEveryting 之后，会觉得系统自带的照片和播放器「有点钝」——不是因为我们功能更多，而是因为**每一帧都更快、更静、更跟手**。
